👨‍💻 About Me

I am a Software Engineer at Karooth IT (BD) Limited, focused on building secure, scalable, and maintainable enterprise applications.

My core expertise is in Angular, TypeScript, Java, and Spring Boot. I work across frontend and backend systems, developing micro-frontends, REST APIs, role-based access control, reporting modules, scheduled workflows, caching, messaging, and file-storage integrations.

I currently contribute to large-scale management information systems, including the South Sudan Safety Net Project MIS and a Madrasa Institute Management Information System.
