## About Me

I am a full-time **Software Engineer at Karooth IT (BD) Limited**, specializing in building scalable, secure, and user-friendly enterprise applications.

My primary frontend stack includes **Angular, TypeScript, JavaScript, PrimeNG, Bootstrap, SCSS, and Chart.js**. I build responsive interfaces, reusable components, complex forms, role-based dashboards, report systems, and micro-frontend applications.

On the backend, I work with **Java, Spring Boot, Spring Security, JPA, Hibernate, Redis, RabbitMQ, MinIO, PostgreSQL, and Microsoft SQL Server**. My experience includes authentication and authorization, REST API development, workflow automation, reporting, scheduled processing, data migration, file storage, and enterprise system integration.

I currently work on large-scale management information systems, including the **South Sudan Safety Net Project MIS** and a **Madrasa Institute Management Information System**.

* Based in Dhaka, Bangladesh
* BSc in Computer Science and Engineering from the University of Dhaka
* Interested in enterprise applications, distributed systems, micro-frontends, and backend architecture
* Portfolio: [raffiul-islam.vercel.app](https://raffiul-islam.vercel.app/)
